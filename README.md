# Customer Churn Prediction System

A machine learning project that predicts customer churn using multiple classification algorithms, exploratory data analysis, and model evaluation techniques.

**Note:** This is a collaborative group project developed as part of a team effort.

## Features

- **Exploratory Data Analysis (EDA):** Analyzed and visualized customer data using Pandas, Matplotlib, and Seaborn to identify potential churn patterns.
- **Machine Learning Models:** Implemented Logistic Regression, Random Forest, Gradient Boosting, XGBoost, and Neural Networks.
- **Model Evaluation:** Compared model performance using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
- **Model Persistence:** Saved trained models using Joblib and Pickle for reuse and potential deployment.

## Technology Stack

- **Language:** Python
- **Data Processing:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost
- **Deep Learning:** TensorFlow, Keras
- **Model Serialization:** Joblib, Pickle
